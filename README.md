# ShopX Marketplace

Responsive ecommerce storefront starter built with Next.js and React.

## Included
- Product catalogue with category filters and search
- Wishlist toggle
- Shopping cart drawer and subtotal
- Responsive mobile and desktop layout

## Demo limitations
Product data is sample data. Checkout, accounts, database, inventory, seller/admin dashboards and real payment processing are not connected yet.

## Run locally
`npm install` then `npm run dev`.
